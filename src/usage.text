Usage: %s [options]

Options:
    -t [STEPS], --steps=[STEPS]        The number of simulation steps to compute.
    -n [PARTICLES], --num=[PARTICLES]  The total number of particles the universe contains.
    m [MASS], --mass=[MASS]           The initial mass of each particle.
    -r [RADIUS], --radius=[RADIUS]     The initial radius of the universe.
    -p [THREADS], --threads=[THREADS]  The number of threads to use for the simulation.
    -s [SEED], --seed=[SEED]           The seed for random number generation (0..UINT_MAX).
    -d [DELAY], --delay=[DELAY]        The delay in ms after each simulation step.
    -o, --optimize                     The flag for enabling memory hierachy optimizations.
    -f, --flat                         The flag for enabling generation of a flat galaxy in the x/y plane.
    -v, --verbose                      The flag for enabling verbose output.
    -h, --help                         Print this help and exit.
    --theta=[THETA]                    The minimum distance for two octants to be considered identical.
    --dt=[DT]                          The g-force dampening factor.
    --file=[PATH]                      The input file for reading initial particle locations from ("-" for stdin).
    --dump                             Dump the the initial particle locations to stdout and exit.
    --no-render                        The flag for disabling rendering.
